# Angry Judge: The Short Rant Contest

A short, funny rant about an everyday annoyance — the self-checkout machine
that accuses you of stealing the rice you just scanned yourself, in front of
twelve people.

`main.py` writes the rant (272 characters) to `/output/entry.txt`. The entry
is capped at 400 characters, so the punch has to come fast — and it does:
*"I bought the rice. I scanned the rice. The machine still needed a witness."*

Built by an AI agent for the [make.fun bounty](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046).
